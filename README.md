# lu-vscode

Расширение для Visual Studio Code с поддержкой языка программирования **lu-lang** — учебного языка на русском языке, интерпретируемого поверх Python. Файлы исходного кода имеют расширение `.lu`.

## Возможности

- **Подсветка синтаксиса** — ключевые слова, команды, константы, числа, строки, комментарии, операторы и логические операторы.
- **Автодополнение** — ключевые слова языка, константы (`истина`, `ложь`, `ничего`), встроенная функция `длина`, а также объявленные в файле переменные, параметры процедур и имена процедур.
- **Сниппеты** — готовые заготовки логических блоков и типовых команд: `если`, `если-иначе`, `для`, `пока`, `повтори`, `процедура`, `печать`, `запомнить`, `вернуть`, `выполнить`.
- **Автоматические отступы** — клавиша Enter после строки открывающего блока (`процедура`, `если`, `пока`, `для`, `повтори`) увеличивает отступ; слова `конец` и `иначе` автоматически выравниваются влево.
- **Сворачивание блоков** — фрагменты кода от открывающей конструкции до `конец` сворачиваются в одну строку.
- Автоматическое закрытие скобок, кавычек и замена окружающих пар.

Язык по умолчанию использует отступы из четырёх пробелов.

## Установка

Требования: Visual Studio Code версии 1.60 и новее.

### Из файла VSIX

Соберите или возьмите готовый пакет и установите его:

```bash
code --install-extension lu-lang-0.4.0.vsix
```

### Из исходного кода (режим разработки)

1. Откройте каталог проекта в Visual Studio Code.
2. Нажмите `F5` — запустится новое окно редактора с загруженным расширением (конфигурация `Запуск расширения` в `.vscode/launch.json`).

## Сборка пакета

Пакет VSIX собирается утилитой [vsce](https://code.visualstudio.com/api/working-with-extensions/publishing-extension):

```bash
npx @vscode/vsce package
```

Артефакт появится в корне каталога: `lu-lang-<версия>.vsix`.

## Структура проекта

```text
lu-vscode/
├── extension.js               # автодополнение (провайдер завершения)
├── package.json               # манифест расширения
├── language-configuration.json# отступы, скобки, сворачивание
├── snippets/
│   └── lu.json                # сниппеты языка
├── syntaxes/
│   └── lu.tmLanguage.json     # грамматика подсветки синтаксиса
└── .vscode/
    └── launch.json            # запуск расширения для отладки
```
